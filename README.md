# ИИ-агент поддержки принятия решений

Веб-приложение для анализа данных дистанционного мониторинга, изображений растений и агрономических наблюдений. Проект предназначен для развития системы прогнозирования количества и качества урожая и выработки обоснованных рекомендаций.

## Что уже реализовано

- Адаптивный интерфейс для компьютера и телефона.
- Диалог с моделью Kimi с потоковым выводом и остановкой генерации.
- Загрузка PNG, JPEG или WebP до 2 МБ для визуального анализа.
- Карточка мониторинга: культура, фаза, площадь, число цветков и плодов, метеопараметры и наблюдения.
- Передача карточки наблюдения вместе с вопросом.
- Локальная история последних сообщений без сохранения изображений.
- Серверная функция `/api/chat`: API-ключ не попадает в браузерную сборку.
- Проверка готовности `/api/status` и понятные состояния ошибок.

YOLO, ChromaDB/RAG и QLoRA пока не встроены как готовые модели: раздел «Архитектура» описывает их место в системе. Количественный прогноз урожайности требует реальных данных и отдельной валидации.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
cp .env.example .env.local
```

Создайте ключ в [Kimi API Platform](https://platform.moonshot.ai/) и укажите его в `.env.local`:

```dotenv
MOONSHOT_API_KEY=ваш_ключ
AI_MODEL=kimi-k2.6
```

Запуск:

```bash
npm run dev -- --host 0.0.0.0 --port 7100
```

Откройте `http://localhost:7100/`. Vite локально обрабатывает те же API-маршруты, которые на Vercel выполняются как Functions.

Без API-ключа интерфейс и все разделы доступны, но отправка вопроса вернёт сообщение о необходимости подключения. Файл `.env.local` исключён из Git.

## Сборка и проверка

```bash
npm run build
npm run lint
```

## Публикация на сайте

Готовый адрес проекта: `https://alexeykutyrev.pro/ai-agentsad.html`. Отдельный поддомен не используется.

1. Выполните `npm run build`.
2. Синхронизируйте готовую страницу, ресурсы и API с основным проектом: `node tools/sync-to-swarm.mjs ../Swarm`.
3. В настройках существующего Vercel-проекта добавьте `MOONSHOT_API_KEY` для Production. При необходимости задайте `AI_MODEL`; по умолчанию используется `kimi-k2.6`.
4. Опубликуйте сайт из `Swarm/dist/`: `vercel --prod`.
5. Проверьте страницу и `/api/status` на основном домене.

В GitHub сохраняется весь исходный код этого приложения. Скрипт синхронизации не удаляет файлы AgroSwarm и других проектов.

## Структура

- `src/components/ChatPanel.tsx` — диалог, вложения и потоковый ответ.
- `src/components/MonitoringPanel.tsx` — карточка наблюдения.
- `src/components/ArchitecturePanel.tsx` — состав исследовательской системы.
- `src/components/AccessGate.tsx` — браузерная парольная форма.
- `src/lib/api.ts` — обращение интерфейса к собственному API.
- `api/chat.ts` — серверный вызов Kimi API и преобразование потока.
- `api/status.ts` — состояние подключения без раскрытия ключа.
- `server/prompt.ts` — системные правила агрономического агента.

## Ограничения

Парольная форма является браузерным ограничением демонстрационного проекта, а не серверной авторизацией. История чата хранится в `localStorage` текущего браузера. Изображения передаются модели только при отправке вопроса и не включаются в сохранённую историю.
